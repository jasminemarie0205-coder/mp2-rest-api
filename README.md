# MP2 REST API

For MP2, I built a REST API with FastAPI that connects to the data pipeline I made in MP1. You can upload a CSV file with `POST /upload`, and the API saves it in memory and gives back an ID along with some basic info like how many rows and columns it has. Then you can use that ID with `POST /datasets/{dataset_id}/process` to clean the data. It checks that the required columns are there and that numeric columns actually contain numbers, and then it can remove duplicates, drop rows with missing values, and remove outliers if you turn that on. After processing, `GET /datasets/{dataset_id}` shows the cleaned rows, and there's also a `GET /health` endpoint to check that the app is running. I also added middleware that gives every request its own ID and logs how long it took, and I wrote tests with pytest to check uploading, processing, and what happens when you ask for a dataset that doesn't exist.
